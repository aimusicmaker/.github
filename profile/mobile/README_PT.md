## Comece com uma ideia simples

1. Escolha uma cena, um clima e dois instrumentos. Abra o gerador de músicas e descreva o que quer ouvir.
2. Ouça a primeira versão: a letra está clara, o refrão se destaca e o final parece completo? Mude uma instrução antes de tentar novamente.
3. Quando tiver um trecho que queira guardar, use o guia de clipes musicais para planejar as cenas e editar no ritmo da música.

```text
Uma música pop acústica acolhedora para uma viagem tranquila de trem de volta para casa. Violão suave e piano delicado, voz intimista, uma estrofe contida e um refrão mais luminoso. Termine suavemente.
```

> Comece com esta descrição e ajuste os instrumentos, os vocais e o clima à medida que escuta.

### Escrever uma música

[Gerador de músicas](https://musicmaker.im/ai-song-generator/) ↗

Um clima, instrumentos e sua própria letra, se tiver.

### Encontrar as palavras

[Gerador de letras](https://musicmaker.im/ai-lyrics-generator/) ↗

Um tema, um ponto de vista e uma ideia para o refrão.

### Criar os visuais

[Gerador de clipes musicais](https://musicmaker.im/ai-music-video-generator/) ↗

Música que você tenha permissão para usar e uma breve descrição da cena.

### Criar uma capa

[Criador de capas de álbuns](https://musicmaker.im/ai-image-generator/album-cover-maker/) ↗

Uma direção visual e, se necessário, imagens de referência com uso autorizado.

### Trabalhar com notas

[Áudio para MIDI (notas editáveis)](https://musicmaker.im/audio-to-midi/) ↗

Um arquivo de áudio para converter em notas editáveis; confira a transcrição.

### Testar um clipe curto

[Ferramenta de clipes musicais curtos](https://musicmaker.im/free-short-music-video-generator/) ↗

Uma cena simples; confira os limites atuais da ferramenta antes de gerar.
