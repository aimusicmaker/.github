## 先从一个小想法开始

1. 选一个场景、一种情绪和两件乐器。打开歌曲生成器，描述你想听到的音乐。
2. 试听初稿：歌词听得清吗？副歌够突出吗？结尾完整吗？每次调整一条描述，再试一次。
3. 找到值得保留的片段后，跟随音乐视频指南安排镜头，再按节拍剪辑。

```text
一首适合安静坐火车回家时听的温暖原声流行歌。轻柔吉他与柔和钢琴，贴近耳边的人声，主歌克制，副歌明亮一些，轻轻收尾。
```

> 从这段描述开始，边听边调整乐器、人声和情绪。
